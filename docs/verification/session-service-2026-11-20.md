# 작업 세션 서비스 검증

Windows와 Node.js 24.16.0에서 `agentic-task-kit@0.2.0-sdk.3`을 빌드해 별도 프로젝트에 오프라인 설치했다. 사용한 패키지 `agentic-task-kit-0.2.0-sdk.3.tgz`의 SHA-256은 `1a90976743caa8a6e0afa83b5d574f4816cf7d5f477bd087dc6aee201f813067`이다.

| 검증 경로 | 확인한 결과 |
| --- | --- |
| Agent 접속 | 공식 MCP TypeScript SDK 1.32.2 클라이언트가 Streamable HTTP로 접속해 도구 16개를 발견했다. 기존 연결을 닫고 새 클라이언트로 같은 세션을 조회했다. |
| 작업 인계와 복구 | 두 단계 파이프라인을 시작한 뒤 클라이언트를 교체하고 HTTP 서버를 강제 종료했다. 같은 저장소로 다시 시작해 인계 메모, 작업 파일, 원래 실행 ID를 확인하고 마지막 체크포인트에서 재개했다. 두 단계가 각각 한 번 실행됐고 다운로드한 결과는 `{"text":"hello!"}`였다. SHA-256은 `f12d6a68872a5d866d2a276153ce287d10e1d4df62300606caed2e2fa1f424e6`이다. |
| 요청 충돌과 범위 | 기존 시작 요청을 반복해 같은 실행 ID를 받았다. 인증 없는 호출, 다른 세션에 연결된 실행 조회, 기대 체크포인트 또는 입력 해시가 맞지 않는 재개 요청은 거절됐다. |
| 사람의 웹 화면 | 실제 Chrome에서 검색과 상세 주소 접속, 인계 편집·저장, 작업 파일 버전 조회, 워커의 처리량, 모바일 너비 390px을 확인했다. 300,093바이트 HTML 다운로드의 SHA-256은 워커가 발행한 `d984b341457d51fe024caf6ad6d569cf1774f237fd58f1dae49166095f161513`과 일치했다. |
| 설치된 예제 | `word-report`의 `normalize`, `count_words`, `format`이 차례로 완료됐다. 서비스를 재시작한 후 같은 세션에서 최종 결과 `{"report":"Words: 6"}`을 읽었다. |

전체 회귀 검사는 워커 하나로 실행해 29개 파일의 테스트 253개가 통과했다. 타입 검사, 113개 모듈의 순환 의존성 및 패키지 import 검사, 기존 SDK의 독립 설치 검증도 통과했다.

저장소에서 `npm run build:all-in-one` 후 `npm run test:session-service`로 독립 설치, 인계, 서버 재시작, 재개 및 산출물 검증을 재현한다. 웹과 MCP의 접속 설정은 [작업 세션 서비스 안내](../session-service.md)에 있다.
