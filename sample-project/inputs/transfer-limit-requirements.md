# 모바일 이체 한도 변경

이 문서는 ATK 활용을 위한 가상의 업무 요구사항이다.

## 목표
고객이 모바일 앱에서 현재 이체 한도를 조회하고 일일/1회 한도를 변경한다.

## 요구사항
- 로그인한 고객만 자신의 이체 한도를 조회하거나 변경할 수 있다.
- 변경 시 추가 인증을 수행하고 인증 결과와 변경 이력을 남긴다.
- 1회 한도는 일일 한도를 초과할 수 없다.
- 고객별 허용 최대 한도를 초과하는 요청은 거절한다.
- 같은 변경 요청이 재전송되더라도 한 번만 처리한다.
- 성공 시 적용된 한도와 적용 시각을 화면에 표시한다.
- 인증 실패, 네트워크 오류, 동시 변경을 구분해 안내한다.

## 확인할 사항
- 고객 등급별 최대 한도와 추가 인증 수단은 아직 정해지지 않았다.
- 기존 한도 조회/변경 API와 감사 로그 보관 정책은 담당자 확인이 필요하다.
- 미확정 정책을 임의로 확정하지 말고 확인 질문과 테스트 항목으로 남긴다.
